# Shelf · 私人收藏展厅

把喜欢的书、电影、游戏和物件放进同一个展厅。记录进度、评分和心得，也可以改造成自己的书架、游戏库或收藏柜。

![Shelf 收藏展厅预览](assets/preview.jpg)

## 可以做什么

- 新建、编辑和删除收藏，为每件收藏添加封面、创作者、年份、标签和心得。
- 上传本地封面，或填入图片链接。
- 按分类和进度筛选，搜索标题、创作者、标签与心得。
- 按最近更新、标题或评分排序，切换卡片和列表视图。
- 查看收藏数量、完成进度和评分统计。
- 导出 JSON 备份，再导入到另一台电脑或浏览器。
- 修改一个配置文件，替换展厅名称、署名、强调色和收藏分类。

## 开始使用

下载并解压项目后，直接用现代浏览器打开 `index.html`。Windows 也可以双击 `start.bat`。

推荐使用固定的本地网址。安装 Node.js 18 或更新版本后，在项目目录打开终端运行下列命令。项目无需安装第三方依赖。

```sh
npm start
```

打开终端显示的 `http://127.0.0.1:8787`。退出时按 Ctrl+C。

首次打开会加载示例收藏。可以在这些示例上编辑，也可以删除示例后录入自己的收藏。

## 保存和迁移收藏

收藏保存在当前浏览器的 `localStorage` 中。它与浏览器及访问地址绑定，刷新后仍会保留。清除网站数据会清掉收藏。直接打开文件时，保存方式还受浏览器对本地文件的支持影响，因此日常使用建议固定采用本地网址。

使用界面上的导出功能保存 JSON 备份。导入最多支持 1,000 条收藏，会按收藏 ID 合并，保留更新时间较新的记录。同一条收藏从备份导入后会继续使用原来的 ID。导入前会验证整份文件，格式错误时会提示。

切换浏览器、端口、文件位置或部署地址后，可以通过导出和导入迁移数据。GitHub 上的代码与浏览器中的个人收藏分别保存，发布网页后，每位访客都使用自己浏览器里的收藏。
建议定期导出 JSON 备份，避免清除浏览器数据时丢失收藏。


## 开发与贡献

代码使用 HTML、CSS 和原生 JavaScript，运行时无需构建。

```text
index.html          页面结构
styles.css          展厅样式
app.js              界面交互与本地保存
collection.js       数据校验、合并、筛选与统计
config.js           名称、主题色与分类
demo.js             首次打开时的示例收藏
assets/             本地图片与预览
tests/              数据处理回归测试
server.mjs          本地静态文件服务
```

运行数据处理测试使用下列命令。

```sh
npm test
```
